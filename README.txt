МОЯ ЗАРПЛАТА — PWA
===================

Файли:
- index.html — застосунок
- manifest.webmanifest — налаштування встановлення
- sw.js — офлайн-кешування
- icon.svg, icon-192.png, icon-512.png, icon-maskable-512.png — іконки

Встановлення:
PWA потрібно відкрити через HTTPS або localhost. Для встановлення на Android:
1. Завантажте файли на статичний хостинг з HTTPS (наприклад, GitHub Pages).
2. Відкрийте адресу в Chrome на телефоні.
3. Меню ⋮ -> "Установити додаток" або "Додати на головний екран".
4. Після першого відкриття застосунок може працювати офлайн.

Логіка розрахунку:
- Базова зарплата 31 000 грн (параметр).
- Норма буднів = будні місяця мінус дні зі статусом "свято".
- Годинна ставка = зарплата / (норма буднів * 8).
- Будній день 12 год: +4 год * ставка * коефіцієнт (1,2).
- Субота/неділя: 8 год = +8 год, 12 год = +12 год, обидва за ставкою * коефіцієнт.
- Будній день "за свій рахунок" віднімає 8 годин ставки.
- Вихідний у будній день і свято не змінюють нарахування (свято виключається з норми).
- Премія = нарахування мінус ставка 12 000 грн (рахується до податків).
- Податки: відсоток від нарахування (за замовчуванням 0; ПДФО 18% + військовий збір 5% = 23%).
- Сума до виплати = нарахування - податки - аванс. Аванс вважається вже "чистою" сумою.
- Дні виплати авансу (22) і основної виплати (7) задаються в параметрах.

Оновлення:
Сторінка завантажується з мережі першою (якщо вона є), тому зміни в index.html підхоплюються
без ручного підняття версії кешу. Якщо змінюєте інші файли — збільште CACHE_NAME в sw.js.

Дані зберігаються локально у браузері цього пристрою: параметри — спільні, позначки днів — окремо
для кожного місяця.
