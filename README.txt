МОЯ ЗАРПЛАТА — PWA
===================

Файли:
- index.html — застосунок
- manifest.webmanifest — налаштування встановлення
- sw.js — офлайн-кешування
- icon.svg — іконка

Встановлення:
PWA потрібно відкрити через HTTPS або localhost. Для встановлення на Android:
1. Завантажте файли на статичний хостинг з HTTPS (наприклад, GitHub Pages).
2. Відкрийте адресу в Chrome на телефоні.
3. Меню ⋮ -> "Установити додаток" або "Додати на головний екран".
4. Після першого відкриття застосунок може працювати офлайн.

Логіка розрахунку:
- Базова зарплата 31 000 грн.
- Годинна ставка = 31 000 / (кількість буднів у місяці * 8).
- Кожна 12-годинна зміна додає 4 години * годинну ставку * 1,2.
- Кожен день "за свій рахунок" віднімає 8 годин базової ставки.
- Аванс віднімається від загального нарахування.
- Премія показується як нарахування мінус ставка 12 000 грн.
- Сума до виплати 7-го числа = нарахування мінус аванс.
- Податки та інші утримання не враховані.

Примітка:
Це початковий робочий прототип. Дані зберігаються локально у браузері цього пристрою.
